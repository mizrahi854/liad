# LIAD — החנות

חנות מוצרי הציפורניים, בנויה ב-HTML / CSS / JS / JSON בלי ספריות חיצוניות.
הקטלוג נבנה אוטומטית מתוך תיקיות הדרייב.

---

## הפעלה

צריך שרת מקומי (הדפדפן חוסם טעינת JSON מקובץ מקומי).

**ב-VS Code:** תוסף **Live Server** ← קליק ימני על `index.html` ← `Open with Live Server`.

**או מהטרמינל:**

```bash
python3 -m http.server 4175 --directory liad-shop
```

ואז http://localhost:4175

## הדפים

| דף | מה זה |
|---|---|
| `index.html` | הקטלוג — סינון לפי קטגוריה/מותג, חיפוש, מיון, הוספה לסל |
| `product.html?id=…` | דף מוצר — גלריה, מפרט, כמות, מוצרים מאותו קו |
| `checkout.html` | תשלום כאורחת — פרטים, משלוח/איסוף, קופון |

### מערכת התמונות

לכל גוון יש כמה צילומים בדרייב, בתיקיות "סגנון 1/2/3". הצינור **ממזג אותם
למוצר אחד** ומסדר את התמונות לפי תפקיד:

1. **בקבוק / אריזה** — התמונה הראשית בכרטיס ובגלריה
2. **סווטצ׳** — הגוון על הציפורן. בדסקטופ מתחלף ב-hover על הכרטיס
3. שאר הצילומים — בגלריית דף המוצר

הסדר נקבע ב-`styles` שבתוך כל כלל ב-`catalog_rules.json`, כך שאפשר לשנות
בלי לגעת בקוד.

**מינימום שתי תמונות לכל מוצר.** למוצרים שהיה להם צילום קומפוזיטי אחד
(בקבוק + ציפורן באותה תמונה), `tools/make_swatches.py` חותך ריבוע ממורכז
על הציפורן ושומר אותו כתמונת סווטצ׳ נפרדת. זו גזירה מהצילום המקורי,
לא תמונה מפוברקת. כרגע: 477 מוצרים עם 2+ תמונות, 4 בלי (אביזרים).

```bash
python3 tools/make_swatches.py --dry-run   # לראות מה ייווצר
python3 tools/make_swatches.py             # ליצור ולעדכן את הקטלוג
```

### חשבונית

לחשבונית יש כותרת ממותגת עם הלוגו של הסטודיו, מספר הזמנה ופרטי הלקוחה.
שני כפתורים:

- **שמירה כ-PDF** — דרך הדפסת הדפדפן (ה-CSS מסתיר הכל חוץ מהחשבונית)
- **שליחה בוואטסאפ** — פותח את וואטסאפ עם סיכום ההזמנה מוכן, אל מספר
  הטלפון שהלקוחה מילאה בצ׳קאאוט. המספר מומר אוטומטית לפורמט בינלאומי
  (`050-123-4567` ← `972501234567`).

  שימו לב: זה פותח את וואטסאפ עם ההודעה מוכנה — הלקוחה לוחצת "שלח".
  שליחה אוטומטית באמת דורשת WhatsApp Business API בצד שרת.

### נגישות (`js/accessibility.js`)

כפתור צף בכל הדפים, עם: הגדלת/הקטנת טקסט (90%–150%), ניגודיות גבוהה,
הדגשת קישורים, ריווח טקסט מוגדל ועצירת אנימציות. ההעדפות נשמרות
ב-localStorage וחלות בכל הדפים.

### הגלריה (`js/gallery.js`)

רכיב עצמאי לשימוש חוזר: מחוות מגע, גרירה בעכבר, ניווט מקלדת
(חצים / Home / End / Esc), ממוזערות, זום בדסקטופ, מעברי fade,
blur-up placeholder ו-prefetch לתמונה הסמוכה.

## הוספת מוצרים מהדרייב

הקטלוג לא נבנה ידנית. הסקריפט סורק את הדרייב, מוריד תמונות ומייצר את `products.json`.

```bash
python3 tools/drive_import.py --scan       # רק סריקה — לראות מה יש
python3 tools/drive_import.py --download   # סריקה + הורדה + בניית קטלוג
```

**כשמוסיפים תיקייה חדשה בדרייב:** מוסיפים לה כלל ב-`tools/catalog_rules.json` ומריצים שוב.
תיקייה בלי כלל פשוט לא נכנסת לקטלוג, והסקריפט מדפיס אותה בסוף כדי שתדעו.

מבנה כלל:

```json
{
  "match": ["Koyo", "פוליג'ל"],   // כל המילים חייבות להופיע בנתיב התיקייה
  "brand": "KOYO",
  "title": "פוליג׳ל KOYO",
  "category": "polygel",
  "price": 89,
  "priceSource": "market",
  "defaultStock": 8,
  "description": "…"
}
```

קובץ עם שם מספרי (למשל `003.jpg`) הופך אוטומטית ל״גוון 003״.

## המחירים — חשוב לקרוא

לכל מוצר יש שדה `priceSource`:

| ערך | מה זה אומר |
|---|---|
| `client` | מחיר שהלקוחה נתנה. אפשר לסמוך עליו. |
| `market` | **מחיר ייחוס** מסקר שוק ב-nail-it.co.il. **חייב אישור לפני עלייה לאוויר.** |

הסקר נעשה על קטגוריות מקבילות, אבל ייתכנו הבדלים בנפח, בגרסה או במדיניות התמחור.
המחירים האלה הם נקודת פתיחה סבירה — לא מחירון סופי.

## מה עובד ומה דורש שרת

### עובד עכשיו

- קטלוג מלא עם סינון, חיפוש ומיון
- עגלה מלאה — הוספה, שינוי כמות, הסרה, נשמרת בין ביקורים
- **בלי הרשמה ובלי חשבון.** אין מסך התחברות בשום מקום.
- מלאי: מוצר שאזל לא ניתן להוספה, ומוצג "נותרו X" כשנשארו 3 ומטה
- העגלה לא נותנת לעבור את המלאי הקיים
- חישוב משלוח (חינם מעל ₪329.90) עם מד התקדמות
- קופון `LIAD10` — 10% לרכישה ראשונה
- צ׳קאאוט עם ולידציה מלאה, משלוח או איסוף עצמי
- חשבונית שניתן לשמור כ-PDF (הדפסה ← שמירה כ-PDF)
- דף ניהול: עדכון מלאי, ייצוא `products.json`, ייצוא הזמנות ל-CSV
- פופאפ 10% אחרי 45 שניות + בכוונת נטישה
- תזכורת נטישת עגלה בכותרת הטאב

### דורש שרת — עדיין לא פעיל

בראש `js/shared.js` יש `export const LEAD_ENDPOINT = null`.
**כל עוד זה null — שום מייל לא נשלח.**

| מה | למה צריך שרת |
|---|---|
| חיוב בפועל | ספק סליקה (Tranzila / Cardcom / Meshulam / Stripe) |
| מייל אישור + PDF ללקוחה | שירות מיילים שמייצר ושולח |
| מתנה דיגיטלית + קוד הנחה | רשימת דיוור + אחסון ה-PDF |
| קוד חד-פעמי אמיתי | מסד נתונים שמסמן קוד כ״נוצל״ — כרגע הבדיקה בצד לקוח וניתנת לעקיפה |
| מלאי משותף | כרגע המלאי הוא לכל דפדפן בנפרד; שתי לקוחות יכולות לקנות את הפריט האחרון |
| הזמנות בדף הניהול | כרגע רואים רק הזמנות שבוצעו באותו דפדפן |
| מייל נטישת עגלה | זיהוי הלקוחה + תור מיילים מתוזמן |
| הגנה על דף הניהול | `admin.html` פתוח לכל מי שיודע את הכתובת |

**לפני עלייה לאוויר חובה:** לחבר סליקה, להעביר את המלאי לשרת, ולהגן על דף הניהול.
