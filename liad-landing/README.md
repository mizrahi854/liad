# LIAD — דף כניסה (Landing)

דף פתיחה עצמאי ב-HTML / CSS / JS / JSON, באותו עיצוב של האתר שנבנה ב-Lovable.
הדף מציג את כל התוכן של האתר המקורי — **חוץ מהחנות והקורסים עצמם** — ומוביל אליהם כשתי "דלתות".

---

## הפעלה

הדף חייב לרוץ דרך שרת מקומי (לא לפתוח את `index.html` בדאבל-קליק —
הדפדפן חוסם טעינת `data/content.json` מקובץ מקומי).

**ב-VS Code (הכי פשוט):**
התקינו את התוסף **Live Server** ← קליק ימני על `index.html` ← `Open with Live Server`.

**או מהטרמינל:**

```bash
python3 -m http.server 4174 --directory liad-landing
```

ואז לפתוח את http://localhost:4174

## מבנה הקבצים

```
liad-landing/
├── index.html          ← המבנה של הדף. מחולק לאזורים עם הערות בעברית.
├── css/style.css       ← כל העיצוב. מחולק ל-22 אזורים ממוספרים עם תוכן עניינים.
├── js/main.js          ← כל הלוגיקה. ללא ספריות חיצוניות.
├── data/content.json   ← ★ כל התוכן. כאן עורכים מוצרים, קטגוריות, שאלות וכו'.
└── assets/
    ├── img/            ← תמונות
    ├── video/          ← סרטוני ההמלצות
    ├── fonts/          ← Heebo, Assistant, Fraunces (מקומיים, ללא Google Fonts)
    └── _originals/     ← גיבוי התמונות לפני דחיסה
```

## איפה עורכים מה

|---|---|
| מוצרים מומלצים, מחירים, מלאי | `data/content.json` → `products` |
| קטגוריות, צ'יפים | `data/content.json` → `categories` / `chips` |
| שאלות ותשובות | `data/content.json` → `faq` |
| סניפים, שעות פתיחה | `data/content.json` → `locations` |
| טיפים / בלוג | `data/content.json` → `journal` |
| כתובות החנות והאקדמיה | `data/content.json` → `links` |
| טיימר וקוד ההנחה בפופאפ | `data/content.json` → `promo` |
| טקסטים של Hero / אודות / אקדמיה | `index.html` (מסומן בהערות) |
| צבעים, גופנים, צללים | `css/style.css` → אזור 01 (`:root`) |

### חיבור שלושת האתרים

כרגע כל הקישורים מצביעים על עוגנים באותו דף. כשהחנות והקורסים יהיו מוכנים,
מספיק לעדכן מקום אחד:

```json
"links": {
  "shop":    "https://shop.liad.co.il",
  "academy": "https://academy.liad.co.il",
  "booking": "https://booking.liad.co.il"
}
```

ה-JS מחליף אוטומטית את כל הקישורים בדף (כל אלמנט עם `data-site-shop` / `data-site-academy`).

## מה כלול בדף

- שורת הכרזות מתחלפת (ניתנת לעריכה ממערכת הניהול)
- הדר דביק + תפריט מובייל
- **Hero** בשכבות — פורטרט, בקבוקים מרחפים, הילות אור, פרלקסה והטיה לפי העכבר
- **שתי דלתות** — חנות / אקדמיה
- **סקשן הגוונים** — צילום יד אמיתי שהלק שעליו מתחלף בגלילה. לכל גוון:
  בקבוק, שם, מספר גוון, מחיר וכפתור שמוביל לדף המוצר
- **קרוסלת מוצרים** — לולאה אינסופית, זחילה איטית, חצים, גרירה, עצירה בריחוף
- קנייה לפי צורך (צ׳יפים) + קטגוריות
- אקדמיה + קרוסלת סרטוני בוגרות
- אודות, טיפים, שאלות נפוצות, סניפים עם ניווט ל-Waze ול-Google Maps
- ניוזלטר + מתנה דיגיטלית
- הודעה קופצת (ניתנת לעריכה מלאה בניהול)
- כפתור נגישות צף — זהה לזה שבחנות
- פוטר

## סקשן הגוונים — איך הלק מתחלף

הצילום הוא צילום אמיתי (`assets/img/hand-real.jpg`), לא ציור. מעליו יושבת
שכבת SVG שקופה שמכילה רק את חמש צורות הציפורניים, ועליהן שלוש שכבות צבע:

| שכבה | מצב מיזוג | מה היא עושה |
|---|---|---|
| `hand__tint` | `multiply` | הגוון מוכפל בצילום, ולכן הצללים, המרקם והאבן שבבסיס נשארים |
| `hand__depth` | `multiply` | קו כהה ורך בשוליים הפנימיים — נותן נפח |
| `hand__gloss` | `screen` | פס אור מכיוון האור שבצילום — מחזיר את הברק |

הגוון עצמו הוא משתנה CSS אחד (`--nail-color`), ולכן המעבר בין גוונים רץ
על ה-compositor: חלק, ובלי ציור מחדש.

**קווי המתאר של הציפורניים נמדדו מהצילום עצמו** ושמורים ב-
`data/shades.json` תחת `hand.nails`. אם מחליפים את הצילום — צריך למדוד
מחדש. הכלי שעשה את זה יורה קרניים ממרכז כל ציפורן ועוצר בגבול: מול
האצבע לפי קפיצה בחום הצבע, ומול הרקע לפי נפילת הבהירות אל הצל.

הגוונים ב-`data/shades.json` הם מוצרים אמיתיים מהקטלוג, וכפתור הרכישה
מוביל לדף המוצר שלהם.

## האוטומציות — מה עובד ומה עוד צריך שרת

חשוב שיהיה ברור, כי זה משפיע על מה שאפשר להבטיח ללקוחה:

### עובד עכשיו (צד לקוח בלבד)

- **פופאפ ההנחה** — נפתח אוטומטית אחרי 45 שניות (ניתן לשינוי ב-`content.json`),
  וגם כשהעכבר יוצא מהחלון (כוונת נטישה). מי שסגר לא רואה שוב במשך 7 ימים,
  ומי שנרשם לא רואה יותר. נשמר ב-`localStorage`.
- **טפסי הרשמה** — ולידציה של המייל, מלכודת בוטים, הודעות הצלחה/שגיאה.
- **קרוסלת הסרטונים, האקורדיון, התפריט, אנימציות הגלילה.**

### עוד לא עובד — דורש שרת

בקובץ `js/main.js` יש קבוע בראש הקובץ:

```js
const LEAD_ENDPOINT = null;
```

**כל עוד הוא `null` — שום מייל לא נשלח בפועל.** הטופס רק מדמה הצלחה
כדי שתראו את חוויית המשתמש. כדי להפעיל באמת צריך לשים שם כתובת של
שרת או שירות דיוור (Brevo / MailerLite / Make / n8n).

הדברים הבאים **לא ניתנים למימוש בדף סטטי** וידרשו צד שרת:

| אוטומציה | מה צריך |
|---|---|
| שליחת ה-PDF במתנה + קוד הנחה למייל | שירות דיוור + אחסון הקובץ |
| קוד הנחה חד-פעמי לרכישה ראשונה | מסד נתונים שמסמן קוד כ"נוצל" |
| חשבונית PDF אחרי רכישה | צד שרת שמייצר PDF |
| הורדת מוצר מהמלאי + "אזל מהמלאי" אוטומטי | מסד נתונים של מלאי |
| דף ניהול ללקוחה (הוספה/מחיקה/עדכון מלאי) | מערכת ניהול מוגנת בסיסמה |
| נטישת עגלה | עגלה מזוהה + תזמון מיילים |

זה שייך לפרויקט **החנות**, לא לדף הכניסה.
דף הכניסה נשאר סטטי ומהיר — וזו בדיוק הסיבה שהוא נטען מיד.

## ביצועים

האתר המקורי היה איטי בעיקר בגלל תמונות כבדות ו-bundle של React.
כאן:

- אין React ואין ספריות — רק HTML/CSS/JS.
- הגופנים מקומיים (בלי פנייה ל-Google Fonts).
- התמונות נדחסו: `hero` ירדה מ-2011KB ל-**188KB**, תמונת האקדמיה מ-1227KB ל-**314KB**.
  סך התמונות: 4.2MB ← **1.5MB**.
- הסרטונים (17MB) מוגדרים `preload="none"` — הם **לא** נטענים עד שלוחצים Play.

המקוריים שמורים ב-`assets/_originals/` למקרה שתרצו לדחוס אחרת.

## הערות

- **קטגוריות ללא תמונה** מוצגות עם רקע זהב עדין במקום תמונה שבורה
  (באתר המקורי הן היו ריקות). כשיהיו תמונות — פשוט הוסיפו `"image"` ב-`content.json`.
- **אין התחברות ואין הרשמה** בדף, בהתאם לדרישה — רק איסוף מייל לרשימת דיוור.
- הדף עובד ב-RTL מלא ורספונסיבי ממובייל ועד דסקטופ.
